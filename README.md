# Faiz Krisnadi

Personal website: <https://faizkrisnadi.com/>.

The website is served by GitHub Pages from `main`. Editable redesign templates, styling, scripts, and illustrations live in `_site-source/`; regenerate the committed pages with:

```sh
node scripts/build-redesign.mjs
```

The pre-redesign website is preserved on [`archive/pre-redesign-2026-10-18`](https://github.com/FaizKrisnadi/faizkrisnadi.github.io/tree/archive/pre-redesign-2026-10-18), at commit `9a33e69e9b88e5c2b1d15bbb53921e3284611333`. See `_site-source/README.md` for maintenance and rollback notes.

Fonts: Newsreader and DM Sans, self-hosted with their SIL Open Font Licenses in `assets/redesign/`. Existing photographs, academic CV, and thesis materials are retained.
